Bambutton

Ein physischer Knopf, der in Bambuddy die Druckplatte freigibt — für zwei Drucker an einem ESP32-C3.

Firmware installieren

  1. ESP32-C3 per Datenkabel an den Rechner stecken.
  2. Auf den Knopf unten klicken und den seriellen Port auswählen.
Dieser Browser kann nicht flashen — bitte Chrome oder Edge am Desktop verwenden. Das Flashen braucht eine sichere Verbindung (HTTPS).

Funktioniert in Chrome und Edge über Web Serial. Firefox und Safari unterstützen das nicht. Beim Update einer bereits eingerichteten Firmware „Erase" abwählen, dann bleiben WLAN und Bambuddy-Einstellungen erhalten.

Danach einrichten

  1. Das Board öffnet das WLAN Bambutton-Setup (ohne Passwort).
  2. Mit dem Handy verbinden — die Einrichtungsseite öffnet sich von selbst. Falls nicht: http://192.168.4.1/ im Browser eingeben.
  3. WLAN auswählen (nur 2,4 GHz), Passwort eingeben, „Verbinden & speichern". Das Board probiert die Verbindung sofort aus und zeigt das Ergebnis samt IP-Adresse an; bei einem Fehler steht der Grund dabei.
  4. Handy oder PC zurück ins Heimnetz und http://bambutton.local/ (oder die angezeigte IP) öffnen: Bambuddy-Adresse und API-Key eintragen, Drucker laden, den Knöpfen zuordnen.

Das Setup-Netz schließt sich nach der erfolgreichen Verbindung von selbst und erscheint nur wieder, wenn das Heimnetz länger nicht erreichbar ist. Knopf A beim Einschalten gedrückt halten öffnet es jederzeit.

Verdrahtung

  1. Knopf A: LED an GPIO3, Taster an GPIO4
  2. Knopf B: LED an GPIO5, Taster an GPIO6

Taster jeweils gegen 3V3 (interner Pull-down), LED über einen Vorwiderstand gegen GND.
