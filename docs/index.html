Bambutton DE EN

Ein physischer Knopf, der in Bambuddy die Druckplatte freigibt — für zwei Drucker an einem ESP32-C3. A physical button that clears the build plate in Bambuddy — two printers on one ESP32-C3.

Firmware installierenInstall the firmware

  1. ESP32-C3 per Datenkabel an den Rechner stecken.
  2. Auf den Knopf unten klicken und den seriellen Port auswählen.
  1. Connect the ESP32-C3 to the computer with a data cable.
  2. Click the button below and pick the serial port.

Funktioniert in Chrome und Edge über Web Serial. Firefox und Safari unterstützen das nicht. Beim Update einer bereits eingerichteten Firmware „Erase“ abwählen, dann bleiben WLAN und Bambuddy-Einstellungen erhalten.

Works in Chrome and Edge via Web Serial. Firefox and Safari do not support it. When updating an already configured board, untick “Erase” so Wi-Fi and Bambuddy settings survive.

Danach einrichtenThen set it up

  1. Das Board öffnet das WLAN Bambutton-Setup (ohne Passwort).
  2. Mit dem Handy verbinden — die Einrichtungsseite öffnet sich von selbst. Falls nicht: http://192.168.4.1/ im Browser eingeben.
  3. WLAN auswählen (nur 2,4 GHz), Passwort eingeben, „Verbinden & speichern“. Das Board probiert die Verbindung sofort aus und zeigt das Ergebnis samt IP-Adresse an; bei einem Fehler steht der Grund dabei.
  4. Handy oder PC zurück ins Heimnetz und http://bambutton.local/ (oder die angezeigte IP) öffnen: Bambuddy-Adresse und API-Key eintragen, Drucker laden, den Knöpfen zuordnen.

Das Setup-Netz schließt sich nach der erfolgreichen Verbindung von selbst und erscheint nur wieder, wenn das Heimnetz länger nicht erreichbar ist. Knopf A beim Einschalten gedrückt halten öffnet es jederzeit. Die Oberfläche gibt es auf Deutsch und Englisch.

  1. The board opens the Wi-Fi network Bambutton-Setup (no password).
  2. Connect your phone — the setup page opens by itself. If not, enter http://192.168.4.1/ in the browser.
  3. Pick your Wi-Fi (2.4 GHz only), enter the password, “Connect & save”. The board tries the connection right away and shows the result including the IP address; on failure it shows the reason.
  4. Reconnect phone or PC to the home network and open http://bambutton.local/ (or the IP shown): enter the Bambuddy address and API key, load printers, assign them to the buttons.

The setup network closes by itself after a successful connection and only reappears when the home network is unreachable for a while. Holding button A while powering on opens it any time. The web UI is available in English and German.

VerdrahtungWiring

  1. Knopf A: LED an GPIO3, Taster an GPIO4
  2. Knopf B: LED an GPIO5, Taster an GPIO6

Taster jeweils gegen 3V3 (interner Pull-down), LED über einen Vorwiderstand gegen GND.

  1. Button A: LED on GPIO3, switch on GPIO4
  2. Button B: LED on GPIO5, switch on GPIO6

Each switch to 3V3 (internal pull-down), each LED through a series resistor to GND.
